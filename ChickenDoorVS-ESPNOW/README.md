# Uber Chicken Door Controller
Projects file is the main controller of the chicken door

**ChickenDoorVS-ESPNOW**
This project controls the opening and closing of the door.  It uses a ESP32 controller to control and communicates to a bridge ESP32 using the ESP-NOW protocol.

Door is open and closed via a Motor controller board

Listens for a manual toggle switch

**Has the following sensors:**
Door open contact
Door close contact
Battery voltage
