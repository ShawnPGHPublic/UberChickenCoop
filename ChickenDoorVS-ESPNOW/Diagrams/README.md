**Parts**

ESP32 board supporting ESP-NOW
L298N Motor Driver
12V 5V 3v 3.3V Solid State Relay
Plastic Reed Switchs (induction)
Toggle switch
Voltage Sensor

**Pins**
* GPIO 25 / 26 / 33 → L298N IN1 / IN2 / ENA

* GPIO 4 → Relay 1

* GPIO 14 / 27 → door opened / closed limits

* GPIO 18 → manual toggle

* GPIO 34 → WWZMDiB voltage sensor S

* Shared GND → voltage sensor, relay, toggle, and both limit switches
